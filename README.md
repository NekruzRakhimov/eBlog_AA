### eBlog - удобное управление статьями

- Создание статьи
- Получение списка статей
- Изменение статьи
- Получение статьи по ID
- Удаление статьи

#### Сущность - статья
- ID - идентификатор статьи
- Title - заголовок статьи
- Description - описание статьи
- CreatedAt - дата создание статьи
- UpdatedAt - дата изменения статьи
